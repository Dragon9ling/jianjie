# 凌龙 · 个人简历网页

单页静态简历站，可直接部署到 GitHub Pages：无构建、无外部依赖、无后端，离线双击 `index.html` 也能正常显示。

## 本地预览

直接双击 `index.html`（或拖进浏览器）。不需要启动任何服务。

## 部署到 GitHub Pages

1. 新建一个仓库，例如 `cv`。
2. 把本目录里的 `index.html`、`assets/`、`README.md`、`.nojekyll` 一并上传到**仓库根目录**（不要放进子文件夹）。
3. 打开仓库 Settings → Pages → Build and deployment：Source 选 `Deploy from a branch`，Branch 选 `main`、目录选 `/ (root)`，保存。
4. 等 1–2 分钟，访问 `https://你的用户名.github.io/你的仓库名/`。
5. 想用自定义域名：根目录放一个 `CNAME` 文件，内容只写域名，再到 Pages 设置里填。

要点：`index.html` 必须在根目录，否则 Pages 不会自动打开首页。仓库名建议用英文，路径越短越稳。

## 想改内容

- 全文在 `index.html` 里，按 `<!-- ===== 小节名 ===== -->` 分段，改文字直接在对应段落里改。
- 联系方式有 4 处：`mailto:` / `tel:` 链接、复制按钮的 `data-copy`、右侧“一页读完”卡片、页脚版权。
- 换简历 PDF：覆盖 `assets/resume-linglong.pdf`，保持同名，页面里的下载链接就不用改。
- 换配色：文件开头的 `:root` 里改 `--accent`（钢蓝）和 `--paper`（纸色）即可，其余颜色都从这两个派生。

## 交互

- 首屏右侧是实时绘制的三角网格，可用鼠标/手指拖拽旋转；`LOD 0 / 1 / 2` 切换面数（320 / 80 / 20 个三角面），“VERTS · TRIS”读数同步变化。
- 邮箱、电话、微信可一键复制，页面底部弹出提示。
- 所有动效在系统开启“减少动态效果”时会自动关闭。

## 说明

- 页面文字依据原始简历润色，事实、时间、荣誉数量未改动。
- 站点不使用任何 CDN，因此在任何网络环境下都不会出现字体或脚本加载失败。
